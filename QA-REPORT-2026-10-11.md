## Issues Found & Fixed

### 🔴 CRITICAL

**1. Dropdown lists rendered BEHIND other form fields (z-index bug)**
- *Symptom:* Harsh reported "dropdown list nhi khul rhi". In the New Admission dialog, clicking Class/Section/Gender opened the list, but it rendered *underneath* the fields below — looking broken/glitched.
- *Root cause:* Radix SelectContent (z-50) vs Dialog content (z-50) — same z-index, and the dialog's stacking context won. Also the list was only 47px wide (popper width not applied).
- *Fix:* SelectContent z-50 → z-[70]; added `min-w-[var(--radix-select-trigger-width)]` so the list matches the trigger width. Same fix applied to the Menu (dropdown menu) component.
- *Verified:* Dropdown now opens at full width (348px), above all fields. ✅

**2. Restore backup BROKEN in browser demo**
- *Symptom:* Harsh reported "restore krne me dikkat". Clicking Restore → Confirm threw an uncaught promise error; the dialog stayed stuck; the database was left CLOSED (app half-broken afterwards).
- *Root cause:* `restoreBackup()` closes the DB and decrypts the backup, then calls `ctx.relaunch()` — which was a *noop* in the browser demo. The app never rebooted to pick up the restored data.
- *Fix:* Implemented a real browser `relaunch()`: reads the decrypted session bytes from memfs (via a new `__readRaw` shim helper that bypasses the virtual-DB interception), re-opens it in sql.js, re-verifies login, persists to IndexedDB, then `location.reload()`.
- *Verified:* Full restore cycle works — backup → restore → reload → data intact (36 students), zero console errors. ✅

### 🟡 MEDIUM

**3. Backup health didn't refresh after "Back up now"**
- *Symptom:* After taking a backup, the Backup Health panel still showed "Overdue / Last backup: Never" (Diagnostics showed the correct state).
- *Root cause:* `HealthPanel` only fetched health on mount; `backupNow()` didn't trigger a refresh.
- *Fix:* Added a `refreshKey` prop to `HealthPanel`; `backupNow()` bumps it on success.
- *Verified:* Health shows "Healthy" with correct timestamp immediately after backup. ✅

**4. New Exam dialog label outdated**
- "Classes (comma separated)" — but it's now checkbox multi-select. Changed to "Classes".

### ⚪ MINOR / COSMETIC

**5. Diagnostics showed "Node undefined"** in the version line (browser has no Node). Now shows "Browser · Chrome …" in the demo.

**6. Diagnostics showed "Database size 0.0 KB"** (the shared handler stats a virtual path). The browser demo now reports the live in-memory DB size via `exportBrowserDb()`.

**7. WASM served with wrong MIME type** — Hostinger serves `.wasm` as `application/octet-stream`, forcing a slower fallback path. Added a `.htaccess` (shipped in the zip) with `AddType application/wasm .wasm` + cache headers. (Upload it with the rest of the files.)
