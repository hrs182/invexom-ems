# EMS — Feature Suggestions for ₹1L+ Positioning
**Context:** School / coaching center / institution market. Current app is already strong (students, fees, attendance, exams, payroll, accounting, inventory, front office, cards, reports, backup + Drive).

## Tier 1 — High value, directly justifies premium pricing

1. **Bulk student import (CSV/Excel)** — Schools have 500–2000 students in registers. Manual entry kills deals. One-click import with column mapping + duplicate detection.
2. **SMS/WhatsApp fee reminders** — The #1 asked feature in school ERPs. Due-date reminders + defaulter follow-ups via SMS gateway (free tier) or WhatsApp. Directly reduces the school's outstanding fees.
3. **UPI fee collection link** — Generate a UPI payment link/QR per student; parent pays from phone; receipt auto-generated on confirmation. (UPI ID field already exists in Settings.)
4. **Timetable management** — Class-wise weekly timetable, teacher allocation, clash detection, printable.
5. **Homework / diary module** — Teachers post homework; parents see it (fits the parent-portal story below).
6. **Parent portal (read-only web view)** — Parents check attendance, fees due, marks, homework. Huge trust-builder for schools; very few offline ERPs offer it.

## Tier 2 — Differentiation vs Tally/competitors

7. **Biometric / RFID attendance integration** — Import attendance from biometric devices (most schools already have them).
8. **Transport GPS tracking** — Bus routes, student mapping, live location for parents.
9. **Library barcode/QR** — Issue/return scan, overdue fines auto-added to fees.
10. **Custom report builder** — Drag-and-drop columns, save templates (beyond the fixed report catalog).
11. **Multi-branch support** — One license, multiple branches with consolidated reports (coaching chains love this).
12. **Staff leave + payroll automation** — Leave deductions auto-applied in salary slips.

## Tier 3 — "High-tech & professional" polish (reliability/UX)

13. **Dashboard widgets customization** — Let the principal choose which KPIs show.
14. **Keyboard shortcuts everywhere** — Power users (accountants) live on keyboards.
15. **Dark mode** — Already has theme toggle; ensure every screen respects it.
16. **Audit log viewer UI** — Show "who changed what, when" (data exists; needs a UI).
17. **Data import/export for masters** — Fee heads, subjects, ledgers via CSV.
18. **Automatic update checks** — In-app "new version available" for the desktop build.

## Suggested packaging for ₹1L+
- **Core (₹49,999):** everything today + bulk import + timetable + homework.
- **Pro (₹99,999):** + SMS/WhatsApp reminders + UPI links + parent portal + transport.
- **Enterprise (₹1,49,999):** + multi-branch + biometric + custom reports + priority support.
- **Annual AMC (₹9,999/yr):** updates + support — recurring revenue without "subscription software" stigma.

## My recommendation
Build Tier 1 first (items 1–6). They are the features school owners *ask for by name* during demos, and each one maps to a pricing tier. Items 1 (bulk import) and 2 (fee reminders) alone win deals against Tally-based workflows.
